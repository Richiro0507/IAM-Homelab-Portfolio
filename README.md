 Identity \& Access Management (IAM) Homelab Portfolio



Hands-on IAM projects focused on identity administration, access management, security, governance, and automation.



# About This Portfolio



I'm an IT professional developing hands-on expertise in Identity and Access Management (IAM). This repository documents enterprise-style IAM scenarios implemented in an isolated virtual lab, including Active Directory administration, role-based access control, employee lifecycle management, and security investigations.



My objective is to develop practical IAM skills across administration, governance, security, and engineering.



# Lab Environment



- Hypervisor: Oracle VirtualBox

- Domain Controller: Windows Server 2025

- Client Workstation: Windows 11 Enterprise

- Directory Services: Active Directory Domain Services (AD DS)

- Domain: corp.example.test

- Networking: Isolated VirtualBox internal network

- Tools: Active Directory Users and Computers, Windows PowerShell, NTFS permissions, SMB file sharing
